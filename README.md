# Demo e-Koko Pintar

Demo sistem pengurusan kokurikulum sekolah **e-Koko** dengan data rekaan (100 murid, 11 guru).
Semua data disimpan dalam pelayar dan diset semula apabila halaman dimuat semula.

Akaun demo (kata laluan `demo1234`): `admin` (SUPERADMIN), `gpkkoko` (GPK Kokurikulum), `cikgu` (Guru Penasihat).
Tekan butang **★ Panduan Demo** untuk pintasan ke setiap ciri.
